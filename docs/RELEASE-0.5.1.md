# Spike 0.5.1

- Le dépôt officiel devient https://github.com/EnzoCx/Spike.
- Les liens du site, des téléchargements et de la documentation utilisent la nouvelle adresse.
- Le site est disponible sur https://enzocx.github.io/Spike/.
- Le système de mise à jour vérifie désormais les releases du nouveau dépôt.

**Migration :** les utilisateurs de 0.5.0 ou antérieur doivent télécharger cette version
manuellement une fois. L'ancien logiciel refuse les nouvelles adresses des assets.
Conservez le nom `DPSMeter.exe` et remplacez le fichier lorsque le logiciel est fermé.
Les préférences et combats restent compatibles et ne sont pas modifiés.
