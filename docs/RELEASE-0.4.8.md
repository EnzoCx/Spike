# 0.4.8 — résumé de combat à copier

- Bouton « Copier » dans le rapport et le mini-meter, pour le combat affiché ou une archive.
- Résumé prêt à coller : cible, durée, total et classement avec les noms, DPS ou HPS et parts.
- Respect du filtre boss/toutes cibles et du mode dégâts/soins affichés.
- Sources non identifiées conservées séparément ; démos et imports non vérifiés signalés.
- Confirmation discrète de copie et message en cas de presse-papiers indisponible.
- Disponible en français, anglais et espagnol, dans les trois thèmes.

Le bouton remplit uniquement le presse-papiers sur demande ; le joueur choisit où coller le texte.

Validation hors ligne : calculs et format du résumé, filtres boss/toutes cibles/soins,
archives pendant les actualisations du direct, succès et échec de copie simulés,
interfaces FR/EN/ES dans les trois thèmes. Aucun combat réel ni presse-papiers modifié
pendant ces contrôles.
