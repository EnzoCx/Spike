## Design Context

### Users
AION 2 Global players who want to see combat results with minimal setup. Initial user plays while development happens: never open a window over their game during verification.

### Brand Personality
Clear, discreet, direct. Prioritize readable numbers and fewer decisions. Provisional product name: DPSMeter.

### Aesthetic Direction
User requests French, English and Spanish, plus multiple themes. Three complete palettes: charcoal, paper and high contrast. Compact native Windows layout, bundled AION 2 class/skill icons with retained notices, and discreet motion. Theme choice is persistent and immediate.

### Design Principles
- One main view for combat, details available by selecting a player.
- Simple settings: language, theme, optional character name, auto-start, always-on-top.
- Separate capture health from actual combat events. Never present a synthetic fixture as live data.
- Keyboard access and text labels; do not depend on class colors.
- Same capabilities in all languages and themes.

Typography: clear / discreet / direct. Rejected default candidates: Inter, Space Grotesk, IBM Plex Sans. Selected Barlow for readable body and Barlow Condensed for compact headings after reviewing the Google Fonts catalog; embed unmodified OFL fonts.

The user rejected the initial button-list demo. Revised direction: desktop analysis
workspace with narrow navigation, aligned player rows, restrained warm accents,
compact numeric hierarchy and a separate click-through mini meter.

### Identity direction — 2026-10-04
User requested a coherent visual direction including a logo. Implemented direction:
combat instrument, graphite / bronze / ivory. Keep DPSMeter as working name.
The symbol is a D built from three ranking bars, sourced from brand/symbol.path.
Use the same master for app, overlay, desktop icon and future website.
See brand/README.md and brand/tokens.css for the palette, assets and usage rules.
Reserve bronze for identity and selection; class colors encode combat data.
Use the exact WPF family name Barlow Condensed SemiBold for the condensed face;
Barlow Condensed alone silently resolves to Barlow in this embedded font set.
